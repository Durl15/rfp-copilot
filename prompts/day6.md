Day 6: voice-note past-performance intake with Muse Voice Transcribe.
1. POST /voice/past-performance (multipart: audio file, firm_id). Transcribe with Meta Muse Voice Transcribe: model muse-voice-transcribe-1.0, file endpoint POST {META_API_BASE}/asr/transcribe, same bearer auth. Check https://dev.meta.ai/docs/speech-to-text for the exact request shape if reachable; if not, implement per that path and log any mismatch. Log the call to llm_calls with feature voice_transcribe and audio seconds if returned.
2. Extraction: one Muse Spark structured-output call (effort low) turns the transcript into one past-performance entry: client, scope, value_range, dates, role, outcome, reference. Every non-null field must be supported by a verbatim quote from the transcript (checked in code, quotes stored in an evidence object). Anything not said in the note is null, never guessed. One retry on a failed check, then 502.
3. Store the result as a pending entry (table pending_entries) with verified=false and return transcript, entry and evidence. POST /voice/confirm {pending_id, edits?} applies optional edits, then adds the entry to the firm past-performance list with verified=true. POST /voice/reject discards it. Confirmed entries survive restarts and are never written to repo files.
4. Emit voice events (voice_transcribed, voice_extracted, voice_confirmed) into the run log format so the UI can show them.
5. scripts/voice_smoke.py: transcribe a local audio file and print the transcript. Support wav, mp3, m4a.
6. Tests with mocks: transcript to entry with valid quotes; fabricated quote rejected; null for unsaid fields; unconfirmed entries do not change go/no-go; confirmed entry with a matching scope moves firm 1 from zero verified matches to one; reject removes it.
